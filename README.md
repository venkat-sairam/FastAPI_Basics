
# Sentinel Project

This is a full-stack backend system with:
- **FastAPI** (`/api`) for API and database interaction
- **PostgreSQL** for data storage
- **Redis** for caching (future)
- **pgAdmin** for DB UI
- **Streamlit** (`/ui`) for user-facing frontend
- All components containerized with **Docker Compose**

---

## 🔧 Prerequisites

- Docker + Docker Compose installed

---

## 🚀 Running the Project

```bash
docker-compose up --build
```
---
